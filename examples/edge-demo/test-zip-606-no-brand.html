JENNi Edge - ZIP 606 Brand Filter

Test the ZIP code 606 functionality where brand information is excluded from nearby store searches.

⚠️ Special Behavior: This demo uses ZIP code 60612 which starts with "606". The brand "Sony" will be automatically removed from search requests to simulate broader product matching.

How to Test:

  • Open browser Developer Tools (F12) and check the Console tab
  • Click the JENNi pill that appears in the bottom-right corner
  • Look for console logs showing "ZIP starts with 606 - removing brand"
  • Notice that the brand field will be empty in API calls
  • Try changing the ZIP to something else (like 90210) to see the brand being included
  • Compare the fetchNodes and resolve payload logs

Expected Console Output:

  • [JenniEdge] ZIP starts with 606 - removing brand from fingerprint
  • [JenniEdge] fetchNodes - ZIP check: { zip: "60612", startsWithWith606: true, originalBrand: "Sony", searchBrand: "" }
  • [JenniEdge] resolve payload with empty brand field
