# JENNi Edge Demo

Minimal end-to-end demo: a one-file overlay client (`edge.js`) and a mock API server with `/resolve`, `/match`, `/inventory`, `/export`, `/test-order`. Product fingerprinting is now handled server-side only.

## Run
- npm script: `npm run edge:demo`
- Server: http://localhost:3100
- Demo page: http://localhost:3100/

## Files
- `edge.js` — overlay script; calls `/resolve` and renders a bottom bar
- `index.html` — fake PDP that loads `edge.js`
- `server.cjs` — Express server with mock endpoints
- `gtm_custom_html_tag.html` — GTM Custom HTML tag body
- `bookmarklet.js` — injects the overlay on any page

## Enhanced Fingerprinting

The overlay now features comprehensive product detection with advanced clothing attributes:

### Core Product Detection
- **GTIN/UPC/EAN extraction** from multiple DOM sources and JSON-LD with validation
- **SKU and style code detection** with platform-specific selectors and format validation
- **Brand extraction** from metadata, microdata, and title patterns with fallback logic

### Advanced Pricing System
- **Multi-format price parsing**: $XX.XX, XX USD, €XX,XX, £XX.XX
- **Sale price detection**: Original vs current price with validation
- **Price ranges**: "From $25", "$50-$100" format support
- **Currency detection**: USD, EUR, GBP, CAD, JPY with symbol recognition
- **Confidence scoring**: High/medium/low confidence indicators

### Clothing-Specific Attributes
- **Size detection**: Letter (XS-XXXL), numeric, fraction, shoe sizes with type classification
- **Color extraction**: Name + hex code mapping, RGB conversion, visual swatch detection
- **Material identification**: Cotton, polyester, wool, etc. from structured data and descriptions
- **Fit classification**: Regular, slim, skinny, loose, oversized, tailored
- **Style/pattern detection**: Solid, striped, plaid, floral, geometric patterns

### Data Quality & Validation
- **Quality scoring**: 0-100% based on identifier strength and attribute completeness
- **Validation system**: Detects ambiguous data, inconsistencies, and invalid formats
- **Confidence indicators**: 🟢 High, 🟡 Medium, 🔴 Low confidence for each attribute
- **Fallback mechanisms**: Parses unstructured descriptions when structured data missing
- **Issue flagging**: Warnings for missing GTIN, price inconsistencies, low confidence data

## Usage
- **Demo server**: `npm run edge:demo` → http://localhost:3100
- **Enhanced test**: Open `examples/frontend/test-clothing-attributes.html`
- **Bookmarklet**: save the content of `bookmarklet.js` as a bookmark; click on any PDP
- **GTM**: paste `gtm_custom_html_tag.html` into a Custom HTML tag; add a PDP trigger
- **Visual checker**: Click the 🔍 button in the panel to see enhanced attributes

## Notes
- This demo returns deterministic mock data based on ZIP code prefix.
- For a CDN deploy: host `edge.js` and point `JENNI_EDGE_SRC` to that URL.
- To target a remote API base, set `window.JENNI_API_BASE` in GTM snippet.
